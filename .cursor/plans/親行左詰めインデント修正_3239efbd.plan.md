# 親行左詰め・子行のみインデント修正

## 目的

- 親行が子行と同じように右へ寄って見える問題を解消する
- 親は「通常のチェックボックス行の開始位置」と同じ左端に揃える
- 子行のみインデント（現状 `pl-6`）を維持する

## 原因

`[habit-list.tsx](/Users/ta2/ALL-DTA2/Develop/dta2/gol/web-app/gol-web/app/dashboard/habit-list.tsx)` の `hasChildren` 分岐で、親行に以下のダミー要素があり、親テキスト開始位置が1列分右にずれている。

- `grid-cols-[auto_1fr_auto]`
- `span.w-5 ... border-transparent`（透明チェックボックス相当のプレースホルダ）

この構造が、親が左詰めにならない直接原因。

## 変更方針

- 親行（`hasChildren` ブランチ）の先頭プレースホルダ列を削除
- 親行グリッドを2列構成に変更して左詰め化
  - 例: `grid grid-cols-[1fr_auto] ...`
- 子行は現状維持（`pl-6` あり）

## 変更対象

- `[habit-list.tsx](/Users/ta2/ALL-DTA2/Develop/dta2/gol/web-app/gol-web/app/dashboard/habit-list.tsx)`
  - 良習慣: `goodTree.map` の `hasChildren` 親行
  - 悪習慣: `badTree.map` の `hasChildren` 親行
  - ボーナス: `bonusTree.map` の `hasChildren` 親行

## 実装ステップ

1. 各 `hasChildren` 親行で `grid-cols-[auto_1fr_auto]` を `grid-cols-[1fr_auto]` へ変更
2. 直下のダミー `span`（`w-5 h-5 ... border-transparent`）を削除
3. レイアウト崩れがないか3セクションを確認
  - 親行左端が通常行のチェックボックス左端に揃うこと
  - 子行 `pl-6` によるインデントが維持されること
4. lints を確認し、新規エラーがないことを確認
