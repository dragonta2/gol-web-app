# GOL ロゴをログイン・サインアップ・マイページに配置

ロゴ画像 `/gol-logo.png`（[gol-web/public/gol-logo.png](gol-web/public/gol-logo.png)）を3画面の上部に表示する。

## 変更対象ファイル

### 1. ログイン画面 - [gol-web/app/login/page.tsx](gol-web/app/login/page.tsx)

現在のヘッダー部分（L74-81）:

```tsx
<header className="text-center mb-8">
  <h1 className="text-4xl font-bold text-cyan-400 mb-2">
    ⚔️ GOL ⚔️
  </h1>
  <p className="text-xl text-zinc-300 mb-1">Gamification of Life</p>
  <p className="text-sm text-zinc-500">〜人生をゲームに、日記を冒険に〜</p>
</header>
```

- `next/image` で `Image` をインポート
- テキストの「⚔️ GOL ⚔️」の上にロゴ画像を追加
- 画像サイズ: 幅200px程度、中央寄せ、下に少しマージン

### 2. サインアップ画面 - [gol-web/app/signup/page.tsx](gol-web/app/signup/page.tsx)

現在のヘッダー部分（L72-78）はログインと同一構造。同じ変更を適用。

### 3. マイページ - [gol-web/app/mypage/page.tsx](gol-web/app/mypage/page.tsx)

- L88 の `<div className="min-h-screen ...">` 直下の `<div className="max-w-4xl mx-auto">` 内、「ダッシュボードに戻る」リンクと「マイページ」見出し（L90-103）の間にロゴを配置
- 中央寄せ、幅200px程度、上下にマージン

## 共通仕様

- `next/image` の `Image` コンポーネントを使用（`src="/gol-logo.png"` / `alt="GOL - Gamification of Life"` / `width={200}` / `height={100}` で `priority`）
- 全画面で同じサイズ・スタイル（中央寄せ）で統一
