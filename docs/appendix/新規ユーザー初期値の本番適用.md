# 新規ユーザー初期値の本番適用

## なぜ初期値が反映されないか

新規サインアップ時の初期状態（50G・権利Aのみ・デフォルト習慣2件・デフォルトToDo1件）は、**Supabase のトリガーと関数**で挿入されています。本番の Supabase で `set-new-user-defaults.sql` を **1回も実行していない** と、DB 上は古い定義のままになり、新規ユーザーに次のような状態になります。

- ゴルドが 10 のまま（50 にならない）
- 権利が未設定のまま（アプリ側のフォールバックで権利Aのみ表示はされる）
- デフォルトToDo（テストタスク）が作成されない

## 本番で行うこと（今後の新規ユーザー向け）

1. Supabase Dashboard にログインする
2. 対象プロジェクトの **SQL Editor** を開く
3. リポジトリの `docs/sql-snippet/set-new-user-defaults.sql` の内容をすべてコピーする
4. SQL Editor に貼り付けて **Run** する（1回だけ）

実行後、**そのあとからサインアップするユーザー**には、初期値が正しく入ります。

## すでにサインアップ済みのユーザー（中村辰医さんなど）向け

SQL を実行しても、**すでに作成されているユーザーのデータは自動では変わりません**。そうしたユーザーには、ダッシュボードの「初期セットアップを適用」ボタンで、後から初期値を適用できます（1回だけ表示され、適用後に非表示になります）。
