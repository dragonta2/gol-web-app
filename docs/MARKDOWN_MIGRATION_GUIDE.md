# マークダウン版からウェブ版へのデータ移行ガイド

## 概要

マークダウン版の日誌データをウェブ版のデータベースに移行する方法を説明します。

## 移行可能なデータ

- **日誌本文** (`今日の日誌`)
- **一言感想** (`一言感想`)
- **権利（ポイント利用）** (`本日の利用ポイント`)
- **AIあらすじ** (`これまでの冒険` / `これからの冒険`)

## 日付フォーマットの変換

- **マークダウン版**: `260116-金` (YYMMDD-W形式)
- **ウェブ版**: `2026-01-16` (YYYY-MM-DD形式)

## 手動移行方法（推奨・簡単）

### 1. テストアカウントでログイン

テストアカウントでログインし、ダッシュボードにアクセスします。

### 2. カレンダーで日付を選択

移行したい日付をカレンダーで選択します（例: 2026-01-16）。

### 3. 日誌データを入力

以下のデータを手動で入力します：

#### 例: 260116-金のデータ

**日誌本文:**
```
0650｜起床
モーニングコールする
0700｜整理｜引き出し
0830｜ラン｜2Km
0850｜冷水シャワー
0930｜デスク向かう
1000｜業務｜全体 MTG
...
```

**一言感想:**
```
今日も仕事や趣味にいろいろ時間を使えた。

ダンスの練習もしたかったけど、仕事の方が結構流動的な流れでできなかった。
...
```

**権利（ポイント利用）:**
- 権利B（お酒を飲む）: 1回
- 権利D（睡眠導入剤）: 1回

### 4. 保存

「日誌を保存」ボタンをクリックして保存します。

## 自動移行スクリプト（上級者向け）

### 必要な環境

- Node.js 18以上
- TypeScript実行環境（`tsx` または `ts-node`）

### セットアップ

```bash
cd gol-web
npm install -D tsx dotenv
```

### 環境変数の設定

`.env.local`に以下を追加（既にある場合は不要）:
```
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
```

**注意**: サービスロールキーを使用する場合は、`SUPABASE_SERVICE_ROLE_KEY`を設定してください（より多くの権限が必要な場合）。

### スクリプトの実行

```bash
# 方法1: tsxを使用
npx tsx scripts/migrate-md-to-web.ts

# 方法2: package.jsonにスクリプトを追加
# "migrate": "tsx scripts/migrate-md-to-web.ts"
npm run migrate
```

### スクリプトの動作

1. マークダウンファイル（`0-monthly-episode-2601.md`）を読み込み
2. 日付パターン（`### 260116-金`など）を検索
3. 最初の2件の日誌データを抽出
4. 日付フォーマットを変換（`260116-金` → `2026-01-16`）
5. テストアカウントのデータベースに挿入または更新

## 移行するデータの例

### マークダウン版（入力）

```markdown
### 260116-金

##### 今日の日誌 ==============

0650｜起床
...

##### 一言感想 ==============

今日も仕事や趣味にいろいろ時間を使えた。
...

##### 本日の利用ポイント ==============

- [x] 権利B｜お酒を飲む
- [x] 権利D｜睡眠導入剤を服用する
```

### ウェブ版（出力）

- **日付**: `2026-01-16`
- **日誌本文**: `0650｜起床\n...`
- **一言感想**: `今日も仕事や趣味にいろいろ時間を使えた。\n...`
- **権利B**: 1回
- **権利D**: 1回

---

## 注意事項

1. **過去の日誌は編集不可**: 過去の日付に移行したデータは閲覧専用になります
2. **権利E**: ウェブ版にも追加されました。マークダウン版から正常に移行されます
3. **ポイント/EXP**: AI判定結果のポイント/EXPは、マークダウン版には記録されていないため、移行されません
4. **習慣データ**: 習慣のチェック状態は移行されません（習慣データは別途設定が必要です）
5. **ToDoデータ**: ToDoの完了記録は移行されません（ToDoデータは別途設定が必要です）

## トラブルシューティング

### エラー: 環境変数が設定されていません

`.env.local`ファイルに以下が設定されているか確認してください：
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### エラー: 認証エラー

テストアカウントでログインしているか確認してください。
または、`SUPABASE_SERVICE_ROLE_KEY`を設定して実行してください（管理者権限が必要）。

### エラー: マークダウンファイルが見つかりません

スクリプトのパスを確認してください。
デフォルトでは `../../md-app/now/story/0-monthly-episode-2601.md` を参照します。
