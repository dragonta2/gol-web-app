# Habitica分析レポート

## 概要

Habiticaは、習慣管理とタスク管理をRPG（ロールプレイングゲーム）の要素でゲーミフィケーションしたWebアプリケーションです。GOLの参考元として、その構造と機能を分析します。

**参考URL:** https://habitica.com/

---

## 1. コア構造とタスクタイプ

### タスクの4つのカテゴリ

Habiticaは実生活のタスクを4つの主要カテゴリに分類します：

- **Habits（習慣）**
  - **目的**: 継続的な行動（良い習慣・悪い習慣、または両方）
  - **例**: 「水を飲む」「爪を噛む」

  - **報酬/ペナルティ**: 良い習慣はXP、ゴールド、マナを獲得。悪い習慣はHPやマナを減らす

- **Dailies（日次タスク）**

  - **目的**: ルーティンやスケジュールされたタスク（毎日または繰り返し）

  - **報酬/ペナルティ**: 完了すると報酬。未完了だと「ダメージ」（HP減少）を受ける

- **To-Dos（やることリスト）**

  - **目的**: 一回限りまたは期限付きタスク

  - **報酬/ペナルティ**: 完了時に報酬。期限超過でもペナルティなし（ただし、長く残すほどXP/ゴールドが増える）

- **Rewards（報酬）**

  - **目的**: ゲーム内ゴールドで購入できるもの

  - **報酬/ペナルティ**: カスタム報酬やゲーム内アイテムを購入可能

### タスクの詳細機能

- **チェックリスト**: DailiesやTo-Dos内にサブタスクを追加可能

- **タグ・フィルター**: タスクを分類・検索可能

- **難易度設定**: タスクに難易度を設定（trivial, easy, medium, hard）

- **統計値の割り当て**: タスクを「Strength」「Intelligence」などの統計値に関連付け可能

## 2. ゲーミフィケーション要素

### アバターとクラス

- **アバター**: キャラクターを作成・カスタマイズ（スキン、アクセサリー）

- **クラス**: Warrior（戦士）、Mage（魔法使い）、Rogue（盗賊）、Healer（治療師）など

- **クラスの影響**: クラスによって統計値やスキルが異なる

### 統計値システム

- **Experience (XP)**: タスク完了で獲得、レベルアップに使用

- **Health Points (HP)**: Dailiesを忘れる、悪い習慣を実行すると減少

- **Mana**: スキル使用に必要

- **Gold**: タスク完了で獲得、アイテム購入に使用

### コレクション要素

- **ペット**: タスク完了で時々卵を獲得、ペットを育てられる
- **マウント**: ペットを進化させてマウントにできる
- **アイテム**: 装備、背景、その他のコレクションアイテム

### ソーシャル機能

- **Party（パーティー）**: 友達とチームを組んでクエストに挑戦

- **Guilds（ギルド）**: コミュニティに参加

- **Quests（クエスト）**: ボスバトルやコミュニティチャレンジ

- **Challenges（チャレンジ）**: コミュニティ主催のチャレンジに参加

## 3. UI/UX構造

### ナビゲーション構造

**Web版:**

- **トップツールバー**: ユーザー統計（ゴールド、ジェム）、通知、メッセージ、ナビゲーションタブ

- **主要画面**: Tasks（タスク）ページがホーム画面

**モバイル版:**

- **メニュータブ**: Shops、Inventory、Social、About

- **ヘッダーバー**: アバター、ユーザー名、通知、メッセージ、設定のアイコン

### タスクページの構造

**4カラムレイアウト（Web版）:**

1. **Habits（習慣）** - スケジュールなし、繰り返し可能な行動

2. **Dailies（日次タスク）** - 特定の日にスケジュールされた行動

3. **To-Dos（やることリスト）** - 一回限りのタスク

4. **Rewards（報酬）** - ゲーム内ゴールドで購入できるもの

**主要機能:**
- タスクの検索・フィルター

- 新規タスクの作成（4タイプすべて）

- ノートのプレビュー（最大8行）

- タスクのドラッグ&ドロップで並び替え

- タスク統計の表示

### タスクのインタラクション

- **Habits**

  - **スケジュール/繰り返し**: 不要（いつでも）、正/負（+と-の両方可能）

  - **完了方法**: 「+」をタップ（良い）、「-」をタップ（悪い）。色が変化して履歴/価値を表示

  - **報酬/ペナルティ**: 良い場合はXP、ゴールド、マナ獲得。悪い場合はHP、マナ減少

- **Dailies**

  - **スケジュール/繰り返し**: 選択した繰り返しスケジュール（毎日、特定の曜日など）

  - **完了方法**: チェックボックスで完了。ストリーク追跡。未完了だとペナルティ（HP減少）

  - **報酬/ペナルティ**: 完了すると報酬。未完了だとHP減少

- **To-Dos**

  - **スケジュール/繰り返し**: 一回限りまたは時々、オプションの期限

  - **完了方法**: チェックボックスで完了。完了すると「完了済み」に移動。古いTo-DosほどXP/ゴールドが増える（上限あり）

  - **報酬/ペナルティ**: 完了時に報酬（期限超過でもペナルティなし）

- **Rewards**
  - **スケジュール/繰り返し**: 購入可能、「価格」はゴールドで設定
  - **完了方法**: クリックで購入/交換
  - **報酬/ペナルティ**: タスク完了を促進するための報酬

### サポートUIコンポーネント

- **クイック編集/モーダル**: タスクタイトルやコンテンツをクリックすると編集モーダルが開く

- **ガイドライン**: 新規ユーザー向けに各カラムの説明を表示（一定数のタスク作成後は非表示）

- **報酬のピン留め**: 報酬（ショップアイテム、アバター装備、背景など）をRewardsカラムにピン留め可能

## 4. リデザインと最近の変更

### ナビゲーションの再編成

- **Inventory（インベントリ）**ドロップダウン: Items、Equipment、統合された「Stable」（ペット&マウント）セクション

- **Shops（ショップ）**ドロップダウン: Market、Quests、Seasonal Shop、Time Travelers

- **Party（パーティー）**: 独自のヘッダーボタン

- **Guilds & Challenges**: トップレベルのナビゲーション項目

### タスクページの改善

- **タスクノート**: 最大8行をインライン表示（編集前でも確認可能）

- **クイック作成ボタン**: 常に表示され、どのタスクタイプでも作成可能

- **タスクカラムのガイドライン**: 新規ユーザー向けの説明

- **スキル**: タスクページの下部にアクションバーとして配置（よりアクセスしやすく）

### インベントリ&ショップの改善

- フィルターコントロール
- 折りたたみ可能なセクション
- 検索バー
- 閲覧しやすさの向上

## 5. UX原則とメンタルモデル

### ゲーミフィケーション要素

- **レベルアップ**: タスク完了でXP獲得、レベルアップで報酬
- **ゴールド**: タスク完了で獲得、アイテム購入に使用
- **HP（体力）**: タスク未完了で減少、リスク要素
- **ストリーク**: 一貫性を促進

### 進捗フィードバック

- **色の変化**: 習慣の色が変化して履歴/価値を表示
- **エスカレートする価値**: To-Dosが古くなるほどXP/ゴールドが増える（先延ばしを抑制）
- **即座の報酬**: タスク完了で即座に報酬が与えられる

### モチベーション要素

- **報酬**: カスタム報酬やゲーム内アイテム
- **説明責任**: パーティー、チャレンジ、ピン留めされた報酬
- **可視化**: 今後のタスク/Dailiesが表示される

## 7. 強みと潜在的な制限

### 強み

- **強力なモチベーション要素**: RPG要素が習慣形成を促進
- **多様なタスクタイプ**: Habits、Dailies、To-Dos、Rewards
- **優れたカスタマイズ性**: タグ、フィルター、難易度設定など
- **コミュニティ/ソーシャル説明責任**: パーティー、ギルド、チャレンジ
- **楽しいデザイン**: アバター、装備、クエストなど

### 潜在的な制限

- **統計/分析**: 基本的なもの以外は限定的

- **RPG要素の複雑さ**: 一部のユーザーにはRPG要素が多すぎる

- **オフライン機能**: 一部のプレミアムアイテムは有料

- **UIの複雑さ**: 機能が多く、初心者には分かりづらい可能性

## 8. GOLとの比較と改善点

### Habiticaの使いづらい部分・分かりづらい部分（GOLで改善すべき点）

1. **UIの複雑さ**
   - Habitica: 機能が多く、初心者には分かりづらい
   - GOL改善案: よりシンプルで直感的なUI

2. **RPG要素の複雑さ**
   - Habitica: クラス、スキル、装備などが複雑
   - GOL改善案: 必要最小限のゲーミフィケーション要素に絞る

3. **統計/分析の限界**
   - Habitica: 基本的な統計のみ
   - GOL改善案: AIを活用したより詳細な分析とアドバイス

4. **タスク管理の柔軟性**
   - Habitica: 4つのカテゴリに固定
   - GOL改善案: より柔軟なタスク管理（SPタスクなど）

5. **日次タスクのペナルティ**
   - Habitica: 未完了でHP減少（厳しすぎる可能性）
   - GOL改善案: より柔軟なペナルティシステム

### GOLの独自機能（Habiticaにない要素）

1. **AI判定機能**
   - 日誌を分析してAIが判定・アドバイス
   - RPG物語風のあらすじ生成

2. **ポイント・EXPシステム**
   - 身体EXP、頭脳EXP、精神EXPの3種類
   - より細かい成長の可視化

3. **権利（ポイント利用）システム**
   - 特定の行動にポイントを消費して実行可能にする
   - より柔軟な自己管理

4. **SPタスク（スペシャルタスク）**
   - 特別な報酬があるタスク
   - より大きな目標への動機付け

5. **月単位の概念**
   - MD版では月単位でデータを管理
   - より長期的な視点での習慣管理

## 9. GOLの改善方向性

### Habiticaから学ぶべき点

1. **ゲーミフィケーションの基本要素**
   - XP、レベル、報酬システム
   - ストリーク追跡
   - 即座のフィードバック

2. **タスクタイプの明確な分類**
   - Habits、Dailies、To-Dosの区別
   - 各タイプに適したインタラクション

3. **ソーシャル要素（将来的に）**
   - パーティー、チャレンジなどのコミュニティ機能

### GOLで改善すべき点

1. **UI/UXの簡素化**
   - Habiticaよりもシンプルで直感的なインターフェース
   - 初心者でも使いやすい設計

2. **AI活用の強化**
   - HabiticaにはないAI判定機能をさらに強化
   - より詳細な分析とアドバイス

3. **柔軟性の向上**
   - より柔軟なタスク管理
   - カスタマイズ性の向上

4. **月単位の概念の追加**
   - MD版の月単位の概念をWeb版にも反映
   - より長期的な視点での習慣管理
