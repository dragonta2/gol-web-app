意志力ではなく、**記録行為そのものを成長のループに変える**ことを目的とする。

## 📋 機能仕様・実装方針（260116更新） --------------

### ⚠️ 廃止機能

**体調・気分スコア機能（260116廃止）:**
- MD版で廃止されたため、Web版でも廃止
- `ai_condition_body`、`ai_condition_mood`カラムはデータベースに残すが、機能としては使用しない
- 統計・分析機能からも「体調・気分スコアの推移グラフ」は除外

### 📊 統計・分析機能の実装方針

**実装しやすい順序（難易度順）:**

1. **ポイント・EXPの推移グラフ** ⭐⭐ 簡単
   - `daily_logs`テーブルに`ai_points_earned`、`ai_exp_body`、`ai_exp_mind`、`ai_exp_spirit`がある
   - 過去のデータを集計して折れ線グラフで表示
   - 複数の系列（ポイント、身体EXP、頭脳EXP、精神EXP）を同時表示可能

2. **習慣の達成率グラフ** ⭐⭐⭐ 中程度
   - `habit_logs`テーブルから過去のデータを取得
   - 週間・月間の達成率を計算（完了した日数 / 総日数）
   - 棒グラフや円グラフで可視化
   - 習慣ごとに色分けして表示

3. **ToDo完了率の可視化** ⭐⭐⭐ 中程度
   - `todo_logs`テーブルから過去のデータを取得
   - 完了率を計算（完了したタスク数 / 総タスク数）
   - 週間・月間の推移を棒グラフで表示

4. **進捗ダッシュボード（週間・月間統計）** ⭐⭐⭐⭐ 複雑
   - 上記の機能を統合
   - 複数の統計を一画面に表示
   - カード形式で各統計を配置
   - タブ切り替え（週間/月間）で表示切り替え

5. **エクスポート機能（CSV/JSON）** ⭐⭐ 簡単
   - 既存のデータをCSV/JSON形式で出力
   - ブラウザのBlob APIを使用
   - ダウンロードボタンを追加

**推奨開始順序:**
1. ポイント・EXPの推移グラフ（データが既にある、実装も簡単）
2. 習慣の達成率グラフ（データ取得が必要だが、ロジックはシンプル）
3. ToDo完了率の可視化
4. 進捗ダッシュボード（統合）
5. エクスポート機能

**必要なライブラリ:**
- `recharts`: グラフ描画ライブラリ（軽量で使いやすい）
  ```bash
  npm install recharts
  ```
