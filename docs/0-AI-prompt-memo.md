ちょっとToDoまわりの要件を整理しよう

ToDoタスクは過去の日付、今日の日付で完了できる。

・過去の日付で完了した場合
→ 確定ボタンを押した日付にスコアが入る（ToDoタスクの完了日とスコアの入る日は関係ない）

・今日の日付で完了した場合
→ 今日の日付か未来の日付のどこかで確定ボタンを押したらスコアが入る。

この場合は、今日より過去の日付の日誌では、一切、未確定に表示はでない。
